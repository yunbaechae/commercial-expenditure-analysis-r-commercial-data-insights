# Commercial Expenditure Analysis Using R for Commercial Data Insights

STAT1378 Coding and Communication in Statistics Assignment 1 (2021)

This assignment analyzed expenditure data for commercial insights using R. Key tasks included loading CSV data, computing totals/conditional sums (e.g., March, cloudy weather), and identifying maximum expenditure periods for business trend spotting.

## Key Tasks
- Loaded and structured expenditure CSV data  
- Calculated total sums and filtered aggregates  
- Identified highest expenditure month  

## Skills Demonstrated
- R programming: data frames, filtering, summarization  
- Commercial data insights: expenditure trends and reporting  
- Statistical aggregation for business analysis
